# 🔗 EmpireHustle Sync Guide

## 🎯 Purpose
This guide ensures that updates to the **EmpireHustle Network** are consistently reflected across both **GitHub** (backend knowledge base) and **Strikingly** (frontend showcase).

## 📂 GitHub → Strikingly Workflow
1. **Update Docs in GitHub**  
   - Edit files in `/docs/` (overview, playbook, dashboards, trackers, propfirm-checklist).  
   - Commit changes with clear version notes (e.g., `update playbook v1.3`).  

2. **Export Key Sections**  
   - Copy highlights from `overview.md` and `playbook.md`.  
   - Use visuals from `/assets/branding` and `/assets/charts`.  

3. **Publish to Strikingly**  
   - Paste polished summaries into Strikingly “About” or “Project” pages.  
   - Embed charts or screenshots where visuals add impact.  
   - Add links back to GitHub for full technical detail.
   -   
 ## 🌐 Strikingly → GitHub Workflow
1. **Update Branding**  
   - Any new visuals or text polished on Strikingly should be saved in `/assets/branding`.  
   - Sync logos, banners, and empire identity assets.  

2. **Mirror Content**  
   - Add polished Strikingly text into GitHub README.md for consistency.  
   - Keep GitHub as the source of truth for technical docs.  

## 🔁 Sync Checklist
- [ ] README.md matches Strikingly “About” page  
- [ ] `/docs/overview.md` updated quarterly and synced with Strikingly “Project” page  
- [ ] `/docs/playbook.md` updated with latest strategy versions  
- [ ] `/docs/dashboards.md` synced with latest performance visuals  
- [ ] `/docs/trackers.md` updated with scaling/retirement triggers  
- [ ] `/docs/propfirm-checklist.md` aligned with funding readiness updates  
- [ ] Assets folder synced with Strikingly visuals
