# 🎨 EmpireHustle Branding Guide

## 🎯 Purpose
This guide defines the **visual identity** of the EmpireHustle Network. It ensures consistency across GitHub, Strikingly, dashboards, and external presentations.

## 🌈 Color Palette
- **Empire Gold (#FFD700)** → Highlights, accents, growth visuals  
- **Midnight Black (#000000)** → Backgrounds, headers, charts  
- **Steel Gray (#2C2C2C)** → Secondary text, containers  
- **Emerald Green (#00A86B)** → Positive ROI, success metrics  
- **Crimson Red (#DC143C)** → Losses, retirement triggers  

## 🔤 Typography
- **Headings** → *Montserrat Bold* (modern, strong)  
- **Body Text** → *Open Sans Regular* (clean, readable)  
- **Code/Docs** → *Courier New* (technical clarity)  

## 🖼️ Iconography
- 📈 Performance → Charts, dashboards  
- ⚙️ Strategy → Playbook, upgrades  
- 🏦 Prop Firm → Readiness checklist  
- 🔁 Trackers → Scaling & retirement  
- 🚀 Roadmap → Future milestones  

## 📂 Asset Usage
- **GitHub** → Store logos, charts, and visuals in `/assets/branding`  
- **Strikingly** → Use polished versions of visuals for public pages  
- **Dashboards** → Apply color coding (green for growth, red for risk)  

## 📑 Guidelines
- Always use **Empire Gold + Black** as the primary theme.  
- Keep visuals **minimal and data-driven**—avoid clutter.  
- Use consistent icons across GitHub and Strikingly.  
- Sync branding assets quarterly to ensure alignment.
